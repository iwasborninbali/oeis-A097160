Program invariants for the A097160 finite certificate

The mathematical cutoff proof is in sources/source-audit.md and result.md. These notes explain why the finite algorithms implement that obligation.

For each segment [lo,hi), the primary sieve marks multiples of each base prime q beginning at max(q*q,ceil(lo/q)*q). Every composite in the segment has a prime divisor q<=sqrt(p)<sqrt(hi), and is therefore marked. A prime is never marked: its only prime divisor is itself, whose square exceeds it. The base list contains every prime through floor(sqrt(upper-1)). Thus the unmarked integers in the segment are exactly its primes. The independent checker uses a separately implemented whole-interval sieve on odd integers, with index i representing 2*i+1.

For odd prime p, the binary Jacobi algorithm computes the Legendre symbol using the supplementary law for 2 and quadratic reciprocity. The optimized table stores this exact algorithm's value for every numerator modulo each odd denominator 1,...,4095. Its modulus 2*j+1 occupies indices j*j,...,j*j+2*j; these intervals partition all 2048^2 entries. After extracting powers of two and applying reciprocity, a table lookup replaces the remaining smaller Jacobi problem.

A supported integer a is composed of the 54 primes <=251. Its mask is the parity vector of its prime exponents: the smallest-factor recurrence XORs the factor's bit with the mask of the quotient. Consequently chi(a)=(-1)^popcount(mask(a) AND signature(p)), where the signature records the negative characters of the basis primes. Unsupported integers use Jacobi directly. This is exact multiplicativity. The mask shortcut is used only when p>251, so none of its basis characters is zero.

The rank arrays index the increasing supported and unsupported position lists. For a candidate start s, the two lists partition [s,s+k-1]. Four-at-once parity calculations merely batch exact tests; the least set bit chooses a nonresidue among those positions. If any tested position x is a nonresidue, every start t in [s,x] is impossible: t<=x<=s+k-1<=t+k-1, so its proposed window contains x. Advancing to x+1 therefore skips no successful window. When all positions pass, the returned window is the first k-run. When s>p-k, every admissible window in 1,...,p-1 has been excluded. The boundary p<=k cannot have a k-run.

Every prime failing this search is rescanned over its full word. A simple consecutive-ones counter returns its exact longest run and the earliest start of that maximum. Selecting the greatest row of length exactly n establishes existence of an n-run as well as absence of an (n+1)-run. The p=2 word has the single nonzero residue 1 and maximum one.

The independent checker uses no primary characters, masks, skip rule, or positive witnesses. Euler's criterion computes characters at prime arguments; its own factor sieve and the already computed smaller arguments give chi(a)=chi(q)*chi(a/q) at composite arguments. It counts runs sequentially. In full mode every unlisted prime must produce a k-run and every listed exception must have the stated exact maximum and first start; an omitted exception is rejected. In sample mode this same implication is checked only for selected primes and every listed exception. The final Python audit independently enumerates all exceptional square words and directly verifies recorded sample witnesses by Python modular exponentiation.

Arithmetic is integral except timings and the explicitly labelled planning extrapolation. The C Euler path uses 64-bit products only when p<=2^32-1, so products of reduced residues are below 2^64; it uses 128-bit intermediates above that bound. The actual certified intervals end below 2^31. Python cutoff and square arithmetic uses arbitrary-precision integers. Intentional wraparound occurs only in the documented unsigned 64-bit sample hash.
